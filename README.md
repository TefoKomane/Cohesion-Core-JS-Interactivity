🚀 Project Overview

The carousel application provides an engaging user experience through dynamic slide navigation, autoplay functionality, smooth transitions, and interactive indicators.

The project was developed collaboratively using a feature-branch Git workflow, where each contributor owned a specific component or functionality.

✨ Core Features
🎯 Navigation Controls
  Previous / Next slide buttons
  Circular slide navigation
  Keyboard-friendly interaction support

🔘 Dynamic Indicators
  Auto-generated carousel dots
  Active slide highlighting
  Click-to-navigate functionality

⏯️ Autoplay System
  Automatic slide progression
  Timer-based transitions
  Improved user engagement

🎞️ Smooth Transitions
  Animated slide changes
  CSS transition effects
  Enhanced UI responsiveness

⚠️ Edge Case Handling
