Cohesion Core JS Interactivity — Carousel Project

Project Overview
A collaborative vanilla JavaScript image carousel demonstrating DOM manipulation, event
handling, and GitHub feature-branch workflow in a team environment.

Core Features
• Navigation controls (Next / Previous buttons)
• Dynamic indicator dots with active state
• Autoplay functionality with timers
• Smooth CSS transitions
• Broken image fallback handling
• Circular slide navigation logic

Technologies Used
HTML5, CSS3, Vanilla JavaScript (ES6), Git & GitHub

Git Workflow
Feature branches used:
• feature/TefoKomane/autoplay
• feature/mahlatse-indicators
• feature/nonkululeko-m-maphanga-transitions

How to Run:
1. Clone repo from GitHub
2. Navigate into project folder
3. Open index.html in browser
   
Learning Outcomes:
DOM manipulation, event listeners, state management, modular JS design, and Git branching
workflow
